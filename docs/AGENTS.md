# Подключение AI-агента

Трекер спроектирован так, чтобы агент и человек работали с одними и теми же
файлами и не расходились. Ниже — минимум, который стоит положить в инструкцию
вашего агента (`AGENTS.md`, `CLAUDE.md` или аналог).

## Чтение

Данные читаются напрямую, без API и без запуска сервера:

```bash
grep "^DEMO-" tracker/tasks.csv                      # все задачи направления
python3 -c "import csv;[print(r['ключ'],r['статус_тег'],r['название']) \
  for r in csv.DictReader(open('tracker/tasks.csv',encoding='utf-8-sig')) \
  if r['статус_тег']!='закрыт']"
```

**Важно:** открывайте файлы с `encoding='utf-8-sig'`. Excel и Numbers оставляют
BOM, и обычный `utf-8` превращает первую колонку в `\ufeffключ` — обращение
по имени `ключ` тогда падает с `KeyError`.

## Запись

Два пути, оба безопасны:

```bash
# 1) через ядро трекера — лок, атомарная запись, git-коммит уже внутри
python3 -c "
import saturday_tracker.tracker_store as s
s.update_ticket('DEMO-5', {'статус_тег':'разработка'}, author='agent')"

# 2) через HTTP API запущенного сервера
curl -X POST http://127.0.0.1:8777/api/update \
  -H 'Content-Type: application/json' \
  -d '{"ключ":"DEMO-5","статус_тег":"разработка","автор":"agent"}'
```

Правка CSV руками тоже допустима, но тогда лок вы берёте сами:

```bash
python3 -m saturday_tracker.ctx_lock acquire tasks.csv --wait 30
# ... правка ...
python3 -m saturday_tracker.ctx_lock release tasks.csv
```

## Правила, которые стоит задать агенту

1. **Сверяйся с файлом перед записью.** Между чтением и записью структура могла
   уйти вперёд: появиться новый тикет, смениться схема. Снимок в контексте
   недействителен — перечитай `head -1 tasks.csv` и максимальный номер ключа.
2. **Ключ не переиспользуется.** Даже если тикет удалён, его номер занят навсегда:
   на него могут ссылаться комментарии и связи.
3. **Двигай статусы по факту, а не в конце работы.** Взял в работу — `разработка`,
   отдал на просмотр — `ревью`.
4. **Закрывая, заполняй `резолюция` и `резолюция_тег`.** Без пост-мортема
   закрытая задача через месяц неотличима от заброшенной.
5. **Давай ссылку, а не пересказ.** `http://127.0.0.1:8777/t/DEMO-2` открывает
   карточку сразу. Пересказ тикета в переписке устаревает при следующей правке.
6. **Обсуждение — в комментарии тикета,** а не только в чате: чат прокручивается,
   `comments/<КЛЮЧ>.md` остаётся и лежит в git.

## Параллельная работа

Несколько агентов на одной машине — это штатный режим: лок разводит их по времени.
Если агенты работают в разных ветках, полезно знать: `tasks.csv` **не** сливается
автоматически при правке одной строки с двух сторон — это честный конфликт,
который git покажет. Комментарии (`comments/*.md`) конфликтуют реже: они
дописываются в конец.
